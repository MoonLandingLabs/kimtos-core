# Changelog

## 1.6.0 — 2026-07-25

- Preview video files with the app's themed player instead of the raw browser controls, and stop playback when you leave the file

## 1.5.0 — 2026-07-25

- Stop offering "Compress to ZIP" on a file that is already compressed — re-zipping it just wraps it in a bigger container

## 1.4.0 — 2026-07-25

- Preview audio files with the app's themed waveform player instead of the raw browser controls, and stop playback when you leave the file

## 1.3.0 — 2026-07-25

- Extract an archive straight from the right-click menu — Extract Here, or Extract to its own folder
- Open and extract tar, gzip and tar.gz/.tgz archives too, not only zip
- Say plainly when an archive is a format we can't open yet, instead of a hex dump

## 1.2.0 — 2026-07-22

- Fill the window, maximized or not, instead of a fixed height
- Edit uploaded text, code, Markdown and JSON files, not just view them
- Colour code and JSON with the app's shared syntax highlighter
- Show only the extracted folder after unpacking an archive
- Say that the storage figure covers every app, and open AnubisDB for the breakdown

## 1.1.0 — 2026-07-21

- Sort folders by their aggregate size in the Size column
- Render Markdown files, and harden the shared safe renderer
- Show full file content in previews, and folder sizes in the list

## 1.0.0 — 2026-07-10

- Initial release.
