# Changelog

## 1.0.4 — 2026-11-25

- Tab icons are requested with the Tabs app's other optional permissions when you open it, so installing Kimtos shows no icon-reading warning.

## 1.0.3 — 2026-11-25

- Page icons come from your browser's own icon cache, so showing your tabs makes no request to the sites they belong to.

## 1.0.2 — 2026-07-22

- Tabs closed with Select and Delete no longer reappear in the list once the undo window lapses.

## 1.0.1 — 2026-07-22

- Deleting one saved session now asks first and offers Undo, like deleting several does.
- A deleted session no longer flickers back into the list.

## 1.0.0 — 2026-07-07

- Initial release.
