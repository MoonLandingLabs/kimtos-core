# Words that are ONLY EVER a misspelling of another word — the fixture that keeps them out
# of the shipped dictionary (extension/public/words.txt).
#
# Grammit's speller treats words.txt as the definition of a real word: an entry in it is
# never flagged, and IS offered as a correction for a near miss. The list used to be derived
# by intersecting a web-crawl frequency list with another web-scraped word list, so common
# misspellings that appear in both survived — `langauge`, `accomodate`, `enviroment`,
# `untill` and `wich` all shipped as dictionary words. A user who typed them got no
# underline, and `langauges` was "corrected" to `langauge` (#961).
#
# Two things read this file, so there is exactly one list:
#   - scripts/gen-words.mjs                            refuses to write a list containing one
#   - extension/src/lib/spellcheck.dictionary.test.ts  fails CI if the committed list has one
#
# RULE FOR ADDING AN ENTRY: it must have no legitimate meaning of its own. `calender` (a
# cloth press), `payed` (nautical), `wether` (a castrated ram), `labelled` (British) and
# `threshold` are all real words that are ALSO frequent misspellings — they belong in the
# rule engine's contextual table (lib/grammarRules/dictionaries.ts), never here. So do the
# apostrophe-less contractions (`dont`, `thats`): several of them (`cant`, `wont`, `lets`,
# `ill`) are ordinary words, and that layer owns all of them.
#
# One word per line; blank lines and `#` comments are ignored.
