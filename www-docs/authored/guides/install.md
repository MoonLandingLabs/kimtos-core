# Install Kimtos

Kimtos replaces the new-tab page in Chrome with a private workspace. It is a browser
extension — there is nothing to install on your computer, and no account required to
start.

## Install

1. Open the [Kimtos listing on the Chrome Web Store]({{chromeWebStoreUrl}}).
2. Click **Add to Chrome**, then **Add extension** when Chrome asks.
3. Open a new tab. That is Kimtos.

Chrome will warn you that the extension can _"read and change all your data on all
websites"_. That sounds alarming, so it is worth being precise about why it asks:

- The **Clipboard** app watches for copy events on pages, so it can offer you your
  clipboard history.
- Importing a **PDF by URL**, and the **weather** and **trending article** cards, fetch
  from other sites directly.
- The **Grammit** writing checker underlines mistakes in text boxes on the web.

Chrome has no way to ask for "some websites, sometimes", so it asks for all of them. None
of what you write is uploaded — see [Privacy](./privacy).

## The first time you open it

A welcome screen appears once. It asks:

- **What should I call you?** — optional. It is only used for the greeting above the
  clock ("Good morning, Sam"). You can change or clear it later in
  **Settings ▸ Personalization ▸ Display name**.
- **Which extra tools to set up.** Their AI models download once, with a progress bar.
  They are free; you can also add them later from the App Store.

The apps {{defaultAppNames}} are **installed for you automatically**. Nothing
downloads for them. The others ({{optInAppNames}}) are added from the App Store.

Then click **Get started**.

::: tip You can change your mind about everything
Every app can be added or removed later from the **App Store** (the grid button, top
right). Nothing you choose here is permanent.
:::

## What you are looking at

|                    |                                                                      |
| ------------------ | -------------------------------------------------------------------- |
| **The dock**       | Your installed apps, along the bottom. Click one to open it.         |
| **The search bar** | Focused automatically — just start typing.                           |
| **The home cards** | Weather, today's tasks, a trending article, and so on. All optional. |
| **Top right**      | Release notes, the **App Store**, and **Settings** (the gear).       |

**Settings** is the gear button, top right.

The [new tab guide](./the-new-tab) walks through all of it.
