# Extension docs

The kimtos browser extension (`extension/`) — a local-first Chrome new-tab
workspace built with Vite.

- [architecture.md](architecture.md) — how the app is built (apps, controllers,
  data layer).
- [creating-an-app.md](creating-an-app.md) — the full checklist for adding a new
  app (scaffold, the seven conventions, storage, glyph, docs, verification).
- [releasing.md](releasing.md) — the tag → build → GitHub Release flow.
- [apps/](apps/) — per-app documentation booklets. The docs site (`make docs`)
  publishes one page per booklet.
