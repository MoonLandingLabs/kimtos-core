# Security policy

KimtOS is a Chrome extension that runs entirely in your browser. It has no accounts and no
servers, so there is no hosted service to attack. Security issues are still possible in the
extension itself (for example a content script, a permission, or a bundled dependency).

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's private reporting:
the **Security** tab of this repository, then **Report a vulnerability**.

Include what you found, the steps to reproduce it, and the extension version (Settings,
About). You will get a reply in the issue thread; fixes ship in the next release.

## Supported versions

Only the latest release is supported.
